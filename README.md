# QuickTrade

A minimal static investing website built with HTML, CSS, and JavaScript.

## Structure

- `index.html` — home page
- `stock.html` — interactive stock dashboard
- `mutual-funds.html`, `futures-options.html`, `ipo.html` — product pages
- `css/` — page styles
- `js/` — page behaviour
- `assets/images/` — images and logos

Open `index.html` in a browser to view the site. The stock dashboard uses local demo data for AAPL, MSFT, TSLA, INFY, and RELIANCE, so it works without an API key or internet connection.
